# MuR-Bedienung

Begriffe für die Arbeit mit simulierten und realen MuR-Robotern in der Desktop-App.

## Begriffe

**Betriebsart**:
Gibt an, ob die Bedienperson mit einer Simulation oder mit realer Hardware arbeitet.
_Avoid_: Betriebsprofil als Bezeichnung für Simulation oder Hardware

**Betriebsprofil**:
Konfiguration für eine Betriebsart und ein konkretes Einsatzszenario. Sie beschreibt das Zielsystem und die dort verfügbaren Funktionen.

**Sitzung**:
Aktueller Arbeitskontext der Bedienperson mit gewählter Betriebsart, Betriebsprofil und Zielsystem. Eine Sitzung kann getrennt oder verbunden sein.

**Preset**:
Benannte, wiederverwendbare Auswahl für einen Einsatz, etwa Betriebsart, Profil, Verbindungsziel, Roboter und Visualisierung. Presets können zwischen Rechnern ausgetauscht werden.

**Startablauf**:
Benannte Gruppe zusammengehöriger Starts für einen Versuch oder eine Entwicklungsaufgabe, die als eine Aktion ausgelöst wird.

**Ansicht**:
Teil der Bedienoberfläche mit einer bestimmten Aufgabe, etwa Visualisierung oder Logs. Eine Ansicht kann zur selben Sitzung gehören, wenn sie aus dem Hauptfenster gelöst ist.

**ROS-Visualisierung**:
Arbeitsbereich für die Darstellung von Daten aus dem gewählten ROS-System und für Diagnosemeldungen zu diesen Darstellungen.

**Gazebo-Weltansicht**:
Grafische Ansicht der simulierten Welt mit Gazebo-spezifischen Werkzeugen.
